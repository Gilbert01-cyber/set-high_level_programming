# python-input_output

## Description

This project covers file input/output (I/O) operations in Python 3. It focuses on reading and writing files, working with JSON, handling exceptions, and using Python's built-in `with` statement for safe file handling.

## Learning Objectives

At the end of this project, you should be able to explain:

- Why Python programming is awesome
- How to open a file
- How to write text in a file
- How to read the full content of a file
- How to read a file line by line
- How to move the cursor in a file
- How to make a `class` implement the `with` statement (context manager)
- What is JSON
- How to serialize an object to a JSON string using `json.dumps`
- How to deserialize a JSON string into an object using `json.loads`

## Requirements

- All files are interpreted/compiled on Ubuntu 20.04 LTS using Python 3
- Files end with a new line
- The first line of all files is exactly `#!/usr/bin/python3`
- Code follows the pycodestyle style guide (version 2.x)
- All modules and functions have documentation
- All files must be executable
