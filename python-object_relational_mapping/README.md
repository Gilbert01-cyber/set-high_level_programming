# 0x0F. Python - Object-Relational Mapping

## Description

This project covers connecting Python scripts to a MySQL database, first
using the raw `MySQLdb` module, then using the `SQLAlchemy` ORM to map
Python classes directly to database tables.

## Learning Objectives

* How to connect to a MySQL database from a Python script
* How to SELECT rows from a MySQL table
* How to INSERT rows into a MySQL table
* What ORM means
* How to map a Python class to a MySQL table using SQLAlchemy
* How to get objects from a MySQL database using SQLAlchemy
* How to commit changes to a MySQL database using SQLAlchemy

## Requirements

* All scripts run on Ubuntu, Python 3
* All scripts are executable and end with a new line
* First line of all scripts: `#!/usr/bin/python3`
* Code follows the PEP8 style guide
* All modules and functions have documentation
